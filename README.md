5.3 Axios Bored API Project

A dynamic Node.js web application that interacts with the Bored API to suggest activities based on user preferences. This project demonstrates backend API integration, asynchronous request handling, and dynamic server-side rendering with EJS.

🚀 Features

Random Activity Suggestion: Get a random activity on initial page load.

Advanced Filtering: Filter activities by category (e.g., Education, DIY, Social) and number of participants.

Asynchronous Logic: Utilizes async/await and Axios for non-blocking API communication.

Dynamic UI: Implements EJS templates to render server-side data conditionally.

Robust Error Handling: Custom logic to handle 404 errors when no activities match the user's specific criteria.

🛠️ Tech Stack

Backend: Node.js, Express.js

HTTP Client: Axios

Template Engine: EJS

Styling: CSS3

Tools: Postman (for API testing)
